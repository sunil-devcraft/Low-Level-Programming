# Low-Level-Programming
This repository explores low-level programming concepts in Python

## Folder Structure  
- `src/math_basics/` – Fundamental ML operations like matrix multiplication and gradient descent.  
- `src/memory_management/` – Understanding how Python and NumPy handle memory.  
- `src/performance_optimizations/` – Vectorization, threading, and multiprocessing.  
- `src/hardware_acceleration/` – Using Numba, Cython, and GPU computing.  
- `benchmarks/` – Performance profiling and time-memory trade-offs.  
- `tests/` – Unit tests for implemented functions.  

## Target Programs  
### **1. Math & Computation**  
- Implement matrix multiplication from scratch.  
- Write a basic gradient descent optimizer.  
- Explore dot product operations with NumPy and compare performance.  

### **2. Memory Management**  
- Investigate Python object memory layout.  
- Implement a custom memory-efficient tensor class.  
- Optimize NumPy memory usage with `np.memmap`.  

### **3. Performance Optimizations**  
- Use NumPy vectorization to replace loops.  
- Compare Python threading vs multiprocessing for ML workloads.  
- Profile Python ML scripts with `cProfile` and `line_profiler`.  

### **4. Hardware Acceleration**  
- Speed up ML computations with `Numba` (JIT compilation).  
- Optimize Python functions with `Cython`.  
- Use GPU acceleration with `CUDA` and `cupy`.
